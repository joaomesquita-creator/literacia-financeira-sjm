# A minha vida, o meu orçamento

Aplicação educativa para o 3.º ciclo — São João da Madeira.

## Publicação
No GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save. Aguardar a publicação e usar o endereço apresentado pelo GitHub.

## Funcionalidades
Orçamento mensal e anual; ajuda em popups; poupança; comparação; imprevistos; cinco conquistas; duas perguntas finais; celebração; certificado nominativo; alertas financeiros; exportação/importação. Sem API, conta de aluno ou gravação automática. O nome do certificado não é exportado.

## Limites
Valores de habitação e TUS herdados da recolha registada em 19/10/2026; restantes montantes são estimativas pedagógicas. Anúncios não representam médias nem disponibilidade confirmada. Validar referências antes da aula. Ano com 12 meses iguais e um único imprevisto. Limiar de pouca folga de 10% é uma regra pedagógica, não orientação financeira oficial.

O certificado reconhece participação, não competências certificadas. A data depende do dispositivo. Logótipo otimizado para publicação web a partir da imagem fornecida pelo responsável. Não publicar sessões nem dados de alunos neste repositório.

Esta edição para publicação foi reconstruída a partir do código e requisitos da conversa. Falta validar no navegador, impressão, acessibilidade e acesso simultâneo em equipamentos escolares. Não há garantia de capacidade ilimitada do alojamento.
